## About the site
A minimal, hand-built portfolio:

- **No framework, no build tooling**: plain HTML, CSS and JavaScript, about 35 KB in total.
- **Project window**: projects grouped by status; picking one replays its key points and shows
  its headline number and links. Arrow keys move through the list.
- **Light and dark themes**: follows your system setting until you use the toggle.
- **Accessible**: keyboard navigable and respects reduced-motion settings.
- **Locked down**: strict Content Security Policy, no third-party scripts, no tracking, no
  cookies.
