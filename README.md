## About the site
A hand-built portfolio set in a living koi pond:

- **No framework, no build tooling**: plain HTML, CSS and JavaScript, about 170 KB in total.
- **Canvas pond**: koi in ten real varieties, six frog and three turtle species, lily pads and
  caustic light, all drawn procedurally (no images). It dims and slows down while you read.
- **Interactive sections**: a frog that hops through my journey, a skill web connecting skills
  to projects, filterable project cards, and a Pond mode with a field guide to every animal.
- **Accessible and fast**: respects reduced-motion and high-contrast settings, and is tuned to
  run smoothly on phones.
- **Locked down**: strict Content Security Policy, no third-party scripts, no tracking, no
  cookies.
